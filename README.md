# Nikhil Magdum — 3D Personal Portfolio

Premium dark cinematic portfolio built with React, TypeScript, Vite, React Three Fiber and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```
